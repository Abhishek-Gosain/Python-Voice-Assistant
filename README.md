# Gideon AI – Python Voice Assistant

Gideon AI is a Python-based desktop voice assistant that allows users to interact with the application using voice commands. It combines **speech recognition**, **text-to-speech**, a **Tkinter GUI**, web search, Wikipedia, and WolframAlpha to perform common tasks and respond to user queries.

## Features

* 🎙️ Voice-based command recognition using **SpeechRecognition**
* 🔊 Text-to-speech responses using **pyttsx3**
* 🖥️ Desktop GUI built with **Tkinter**
* 🔎 Google search through voice commands
* ▶️ YouTube search and browser integration
* 📚 Wikipedia information lookup
* 🧮 WolframAlpha-based query handling
* 🎵 Local music playback
* 🎬 Local video playback
* 💻 Basic system commands such as shutdown
* 👤 User name recognition and personalized responses
* 🧵 Threading for handling voice interaction with the GUI

## Technologies Used

* **Python**
* **Tkinter**
* **SpeechRecognition**
* **pyttsx3**
* **Wikipedia API**
* **WolframAlpha API**
* **Web Browser**
* **Threading**

## Example Voice Commands

The assistant can respond to commands such as:

* "Search Google Python"
* "Search YouTube AI"
* "Open Google"
* "Open YouTube"
* "Search Wikipedia ..."
* "What's up?"
* "Play music"
* "Play video"
* "Go offline"
* "Shutdown"

## Project Purpose

This project was developed to explore **voice-based human-computer interaction**, Python automation, API integration, speech processing, and desktop application development.

It demonstrates how different services and Python libraries can be combined to create an interactive voice-controlled assistant.
